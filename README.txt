Matrero Sailing Team – static website
=====================================
Open index.html in a browser, or upload the whole folder to any web host
(Netlify, GitHub Pages, cPanel, S3, etc.). No build step or server code needed.

Pages
  index.html      Home (Matrero -> Encounter)
  matrero.html    Matrero: gallery, regatta results, history
  encounter.html  Placeholder (coming soon)
  contact.html    Placeholder (coming soon)

Languages: EN/ES toggle in the header (remembered in the browser).
Images: /images. Texts for Matrero (results, history, gallery captions) live in js/matrero.js.
Fonts load from Google Fonts (internet connection needed for the exact typefaces).
